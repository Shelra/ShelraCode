# Lane 09 — sources

Every source below was fetched on **2026-09-08** unless otherwise noted. Sources marked
`UNVERIFIED` could not be fetched or contained no usable figure; sources marked `NOT FOUND` were
sought and did not yield the number wanted. Nothing in the lane report is recalled from model memory.

**Access constraints for this session, recorded for the audit trail:**
- `WebSearch` was **unavailable**: the session had already consumed its full budget (200/200 calls)
  before lane 09 started. Zero searches were run by this lane. All discovery was by direct URL.
- `export.arxiv.org/api/query` returned **HTTP 429** on every attempt across ~50 minutes, via both
  the `arxiv-search` skill script and raw `curl` with a polite User-Agent. The arXiv **API** was
  therefore unusable; individual `arxiv.org/abs/` and `arxiv.org/list/<cat>/<YYYY-MM>` pages were
  fetched successfully via WebFetch and are the arXiv evidence below.
- `web.archive.org` is blocked by the tool ("Claude Code is unable to fetch from web.archive.org"),
  so no historical pricing snapshots could be retrieved. Historical prices were instead read off
  vendors' **current** price pages, which still list dated legacy model IDs.
- `openai.com/index/*` and several retailer pages returned HTTP 403.
